# Digital Shield Defenders

ПРОМТ ДЛЯ LOVABLE — InfoQuest: Scutul Comunității Digitale

Скопируй всё, что ниже, в чат Lovable как первый (или уточняющий) промт.

1. О проекте

Создай веб-приложение InfoQuest — двуязычную (румынский 🇷🇴 / русский 🇷🇺) образовательную игру о цифровой безопасности для школьников, учителей, родителей и всего местного сообщества (Молдова).

Формат: карта из 8 миссий, расположенных вокруг центрального светящегося щита (как на референс-изображении — неоново-синяя эстетика, тёмный фон, элементы схемотехники/circuit-board на фоне, жёлтые пунктирные тропы, соединяющие узлы-миссии).

MVP (доступно для прохождения сейчас): миссии №2, №4, №5. Остальные 5 миссий (№1, 3, 6, 7, 8): видны на карте с бейджем «Скоро / În curând», кликабельны только для просмотра тизера (модальное окно с описанием и надписью «Скоро откроется»), без прохождения.

Переключатель языка RO ⇄ RU должен быть в шапке (флажки или aббревиатуры), мгновенно переводит весь интерфейс и контент миссий без перезагрузки страницы.

2. Сюжет игры

Город подключился к единой цифровой платформе сообщества — Rețeaua Comunității / Сеть Сообщества. Но в сети завёлся анонимный актор, известный только как Umbra / Тень — он взламывает аккаунты, звонит жителям от имени операторов связи, публикует поддельные видео и сеет слухи, стравливая румыно- и русскоязычных пользователей города.

Хранитель городской цифровой безопасности — древний страж-протокол по имени VIG (сокращение от Vigilent/Vigilent — «Бдительный»), пробуждается и появляется в виде синего бронированного существа (см. блок «Миссия 7» на референсе). VIG не может действовать в одиночку — ему нужен детектив-стажёр (игрок).

Игрока набирает Патруль InfoQuest — шесть наставников, изображённых в центре постера: учитель (логика и факты), мама (эмпатия и семейная безопасность), школьница и школьник (сверстники-свидетели), предпринимательница (финансовые обманы) и мужчина в форме (техническая экспертиза). Каждая миссия открывается одним из наставников, который встречает игрока коротким сюжетным брифингом.

Цель игрока — пройти 8 расследований (кейсов), закрыть 8 «трещин» в щите города и вытеснить Umbra из Rețeaua Comunității. За каждую пройденную миссию щит в центре карты подсвечивается на 1/8 сильнее (визуальный прогресс-бар в форме самого щита).

3. Технический стек и структура

React + Tailwind (стандарт Lovable), компонентная архитектура.

i18n: объект переводов { ro: {...}, ru: {...} }, весь текстовый контент вынесен в JSON/объект, ничего не хардкодить в разметке.

Роутинг: / (карта миссий), /mission/:id (сцена миссии), модалки поверх карты для заблокированных миссий и для нижних 4 блоков.

Состояние прогресса — в localStorage (пройденные миссии, XP, открытые бейджи).

Полная адаптивность: мобильная версия — карта миссий превращается в вертикальный скролл-список карточек вместо созвездия-щита.

4. Дизайн-система

Фон: тёмно-синий/чёрный градиент с полупрозрачным паттерном печатной платы (circuit board), как на референсе.

Акценты: неоновый голубой/циан (#4FD1FF-подобный) для щита и линий-троп, золотисто-жёлтый для номеров миссий и пунктирных линий-путей.

Заголовок игры — крупный жирный шрифт в стиле «городской герб + технологии» (можно использовать связку щита с иконкой лупы/сканера, как в логотипе на референсе).

Каждая миссия — карточка с толстой цветной рамкой (свой цвет на миссию, как на референсе: красный, синий, зелёный, голубой, розовый/фиолетовый и т.д.), иконкой-иллюстрацией сверху и коротким названием снизу.

Пройденные миссии — рамка становится сплошной и светится; заблокированные — приглушены, с полупрозрачным замком и бейджем «Скоро».

Анимация: точки-огоньки бегут по жёлтым пунктирным тропам между узлами при наведении/загрузке страницы.

5. Все 8 миссий (карта)

Для каждой — двуязычное название, иконка/сюжет иллюстрации, статус.

Contul compromis / Взломанный аккаунт — статус: Скоро. Тема: захват аккаунта через слитый пароль, признаки взлома, двухфакторная аутентификация.

Apelul fals de la operator / Фальшивый звонок оператора — статус: играбельно (MVP). Тема: звонок мошенника с просьбой продиктовать код из SMS.

Scam sau ofertă reală? / Скам или реальное предложение? — статус: Скоро. Тема: отличить настоящий подарок/вакансию/грант от приманки.

Deepfake Detective / Детектив дипфейков — статус: играбельно (MVP). Тема: анализ подделанного видео через доску доказательств.

Detectivul bilingv / Двуязычный детектив — статус: играбельно (MVP). Тема: сравнение одного и того же сообщения на RO и RU — где добавлены эмоциональные манипуляции при переводе.

Orașul sub asediul zvonurilor / Город под осадой слухов — статус: Скоро. Тема: карта распространения слуха по городу, как остановить дезинформацию.

Apără comunitatea de troli / Защити сообщество от троллей — статус: Скоро. Тема: как отвечать на троллинг и агрессию в комментариях, не разжигая конфликт; здесь появляется VIG.

Capcana linkului fals / Ловушка фальшивой ссылки — статус: Скоро. Тема: как распознать фишинговую ссылку/QR-код и поддельную форму входа.

Все 8 карточек кликабельны:

Клик по играбельной миссии → переход на /mission/:id.

Клик по миссии «Скоро» → модалка с иллюстрацией, кратким описанием сюжета миссии (2–3 предложения) и кнопкой «Понятно» / «Am înțeles».

6. Педагогический цикл (обязателен для всех 3 миссий MVP)

Каждая миссия — 4 экрана/шага внутри одной сцены:

Сюжетная ситуация — короткая сцена (текст + иллюстрация/аудио), наставник вводит в контекст.

Решение — интерактивный выбор игрока (несколько вариантов ответа, drag-and-drop, аудиоплеер с кнопками реакции и т.п.).

Демонстрация последствий — анимированный/иллюстрированный результат выбора: что произошло бы при правильном и при неправильном решении.

Короткая теория — карточка «Что нужно запомнить» (3–5 пунктов) + XP-награда и открытие бейджа.

Миссия 2 — Apelul fals de la operator / Фальшивый звонок оператора

Интерфейс: имитация экрана входящего звонка + аудио/текстовый диалог с «оператором», который под разными предлогами просит продиктовать код из SMS.

Решение: игрок в реальном времени выбирает реплики ответа (кликабельные кнопки-реплики) или решает положить трубку/заблокировать номер.

Последствия: если код продиктован — анимация «аккаунт скомпрометирован»; если отказано — «звонок сброшен, номер в чёрном списке».

Теория: «Ни один банк или оператор никогда не спрашивает код из SMS» и т.д.

Миссия 4 — Deepfake Detective / Детектив дипфейков

Интерфейс: видеоплеер с манипулированным роликом + «доска доказательств» (evidence board) — набор кликабельных зон-подсказок (мигание, несовпадение губ и звука, странное освещение, артефакты по краю лица).

Решение: игрок отмечает на доске найденные признаки подделки, затем выносит вердикт «реально / дипфейк».

Последствия: сравнение с оригинальным видео, подсветка пропущенных признаков.

Теория: чек-лист «5 признаков дипфейка».

Миссия 5 — Detectivul bilingv / Двуязычный детектив

Интерфейс: два окна текста рядом — одно и то же сообщение на румынском и на русском.

Решение: кликабельное выделение слов/фраз, которые добавляют эмоциональную манипуляцию в одной версии по сравнению с другой (например, усиленные слова, ложная срочность).

Последствия: подсветка найденных и пропущенных манипуляций, объяснение разницы.

Теория: «Как эмоциональные слова меняют восприятие одного и того же факта».

7. Геймификация

XP-бар в шапке, растущий после каждой пройденной миссии.

Бейджи (иконки-медали) за каждую из 3 миссий MVP + отдельный «финальный» бейдж-щит, который активируется, когда открыты все 3 (сейчас) — с текстом-заглушкой «Полный щит откроется, когда выйдут все 8 миссий».

Центральный щит на карте визуально «зарастает трещинами/светится» пропорционально пройденным миссиям.

8. Нижние 4 блока (тоже все кликабельные!)

На референсе внизу — 4 пустых плейсхолдера. Сделай их живыми интерактивными блоками:

SIGLA ECHIPEI / Логотип команды — кликабельная область-круг с drag-and-drop загрузкой изображения (или заглушка "Загрузить логотип"), при клике без файла — просто подсказка-тултип.

COD QR / QR-код — сгенерированный QR-код (можно через библиотеку типа qrcode.react), ведущий на текущий URL приложения; клик — увеличение QR в модалке + кнопка «Скачать».

MEMBRII ECHIPEI / Команда проекта — клик открывает модалку со списком участников (плейсхолдеры: Имя, Роль — оставь поля для заполнения текстом-заглушкой «Имя Фамилия — Роль»).

DEMONSTRAȚIA JOCULUI / Демонстрация игры — клик открывает модальный видеоплеер (см. раздел 9 ниже про видео).

9. О видео-ссылках (важно!)

⚠️ У меня нет реального готового видео с демонстрацией игры — такой ролик ещё не записан, поэтому я не могу подставить в промт настоящую рабочую ссылку (придумывать несуществующий URL я не буду, он не будет работать).

Вставь в промт для Lovable видео как плейсхолдер-переменную, чтобы легко подставить свою ссылку позже:

const DEMO_VIDEO_URL = "https://www.youtube.com/embed/ЗАМЕНИ_НА_СВОЙ_ID";


Когда запишешь демо (например, экран-запись прохождения 3 миссий), самый простой путь:

Загрузить ролик как Unlisted/неразмещённое видео на YouTube — получишь ссылку вида https://www.youtube.com/embed/xxxxxxxx, она подставляется в <iframe> напрямую.

Либо записать через Loom — тоже даёт готовую embed-ссылку.

Я могу помочь дальше:

написать сценарий (раскадровку) для самого демо-видео по 3 миссиям MVP;

собрать сам ролик, если у тебя будут скринкасты/материалы — просто пришли их.

10. Доступность и мелочи

Весь интерактив (карточки миссий, доска доказательств, реплики звонка, выделение слов) — доступен с клавиатуры и имеет aria-label на обоих языках.

Контраст текста на тёмном фоне — не ниже AA.

Все иконки/иллюстрации — оригинальные векторные/SVG или сгенерированные, без чужих логотипов и брендов.
